
# SharePal — Gaming Gadgets on Rent 🎮

A responsive recreation of the [SharePal Gaming Gadgets Rental Page](https://sharepal.in/bangalore/gaming-gadgets-on-rent), built as part of a frontend development assignment.

The project aims to replicate SharePal's original design, layout, typography, product listings, and user interactions while maintaining a clean, responsive, and user-friendly experience.

## ✨ Features

- 🎨 SharePal-inspired UI and design system
- 📱 Responsive layout for desktop, tablet, and mobile
- 🧭 Navigation and gaming category selection
- 🎮 Gaming product cards and listings
- 📅 Rental date selection interface
- 💬 Interactive FAQ accordion
- 🖼️ Product imagery and reusable UI components
- ⚡ Smooth transitions and hover effects
- 🔗 Functional navigation and interactive elements

## 🛠️ Tech Stack

- **React.js** — Frontend development
- **Vite** — Development server and build tool
- **JavaScript** — Application logic
- **CSS / Tailwind CSS** — Styling and responsive design
- **Lucide React** — Icons (if used)

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone <your-repository-url>
cd <your-project-folder>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

The interface is designed to adapt to different screen sizes while preserving usability, consistent spacing, and visual hierarchy.

- **Desktop:** Full navigation and multi-column layouts
- **Tablet:** Flexible layouts and adjusted spacing
- **Mobile:** Compact navigation and touch-friendly controls
